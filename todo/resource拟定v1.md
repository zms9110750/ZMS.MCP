## 约定

- 参数类型用 **C# 语法**：`string` = 必填；`string?` = 可空（默认 `null`）。`int` / `bool` / `string[]?` 同理。**默认值写在参数表的"参数校验"列里。**
- 返回恒为 markdown 文本（`string`）；失败时第一段以 `Error: ` 开头。
- **缺凭据 / 凭据对不上不算失败**——它们是两段式的正常路径。
- `cookie`：**凭据**。算它**最少要知道路径 + 大小**（所以不必读内容也能拿到）；读过全文的话，**内容与编码**也算进去。**校验时还会比修改时间**——哪怕内容一字没动，只要被人改过，就对不上。改到已有内容时要带它（`write`/`replace`/`delete`/`move`）。
- `key`：**缓存条目的标识**——随机分配的 GUID。用来从 `cache` 里取条目，**不是**凭据。两者不是一个值。
- `session`：FTP 会话，也是 `target` 的一种取值。
- 寻址：`target` 空 = 本地（`path` 是全称，可带盘符）；`ftp:` 前缀 = FTP 会话（`path` 是远端纯路径）；其余非空 = **压缩包**路径（`path` 是压缩包内的纯路径）。**认不出来报错，不降级到本地。**
- **压缩包一律写全"压缩包"**，不简称"包"——免得和网络包之类的混。
- **四级标题只写"情况"**，每个情况下面两段：**行为**，然后 **返回**（预期返回什么）。不是"情况"的说明，写成普通段落。

## 每个工具为了什么

对照 `todo/Resource工具痛点.md`（[真] = 做不到或只能靠每次手写；[绕] = 能做但要绕）。

| 工具 | 为了什么 | 对应痛点 |
|---|---|---|
| `read` | 看到内容；**看完整份换一个凭据** | A1 / A3 / A4（大文件里定位、按段读、匹配带上下文）、A2（编码不是 UTF-8）、**B3（凭据）** |
| `list` | 知道里面有什么；**完整列过换目录树凭据** | A5（文件多大/何时改/什么编码）、A6（目录里哪个最近改/目录多大/两目录差）、E1（不解压看压缩包内） |
| `write` | 新建 / 覆写；**覆写前先验凭据** | **B2（并发写同一份）**、**B3（读到的和写回去的之间被改过）** |
| `replace` | 改已有内容里的某几处；**改之前先验凭据** | **B3** |
| `delete` | 删掉它；**进回收站** | **B1（删除不可逆）** |
| `move` | 换个位置。**为的就是那两种要凭据的情况**：目标已有内容时的覆盖、文件夹合并 | 母题 3 —— 放着不管，AI 自己走命令行去做合并，就是**直接替换**，没人拦 |
| `copy` | 跨存储搬东西：**下载 / 上传 FTP** | D1（访问 FTP）—— 清单里**没有"复制"独立条目** |
| `fetch` | 拿到网络上的东西；**下载受限流约束** | C1（同一 URL 读两次要跑两遍）、C2（内容直接进上下文）、**C5（限流，作用于下载）** |
| `cache` | 回看**取回来的东西**（http 全文、FTP 读取）；**进缓存不等于会命中** | C1、C3、C4、C6 |
| `login` / `logout` | 走 FTP 这条路 | **D1（访问 FTP）** |
| `browse` | 拿到 JS 跑完的页面；把验证交给用户过 | C7（动态 JS 渲染）、C8（整站拦截）、**F1 / F2（人机验证、AI 不该独自做的事）** |
| `track_archive` / `confirm` | 压缩包走拟定：**追踪一个包 → 攒改动 → 落盘** | **E3（压缩包内写 / 删）**——改一个条目要重写整包，所以攒起来一次落盘 |

**清单里有、但没有任何工具接住的**：A6 里"两个目录差在哪"这一半。

## 一、读取

### 1. 读内容 `read`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 在哪个存储/容器上读：空 = 本地；`ftp:<session>` = 会话；其余 = 压缩包路径 | 默认 `null`。非空时先认它是什么；认不出来报错。是压缩包时，压缩包文件必须存在——**例外：正在被追踪、还没落盘的那个包也认**（拿追踪给的 `cookie` 去读它） |
| `path` | `string` | 目标内的路径 | 必填。`target` 为空 → 绝对路径；`target` 非空 → 压缩包内的纯路径，不得带盘符 |
| `skipline` | `int` | 跳过多少行 | 默认 `0`。**先于 `offset` 执行** |
| `offset` | `int` | 跳过多少字符 | 默认 `0`。在 `skipline` 之后执行 |
| `length` | `int` | 至多展示多少字符 | 默认 `5000`。**上限 `16000` 字符** |
| `takeline` | `int` | 至多取多少行 | 默认 `0` = 不限 |
| `encoding` | `string?` | 按什么编码解 | 默认 `null` = BOM → 严格试 UTF-8 → 拒绝；给了但解不出来 → 报错 |
| `regex` | `string?` | 在内容里搜索 | 默认 `null`。正则语法非法 → 报错 |
| `cookie` | `string?` | 追踪 cookie | 默认 `null`。**只在要读"正在被追踪、还没落盘"的那个压缩包时给** |

常量：

- 单次交付上限 `16000` 字符 —— 就是 `length` 的上限
- 正则命中分级：`>20` 只给命中行；`>5` 给上下 1 行；`≤5` 给上下 3 行

**缓存：进缓存 ≠ 命中缓存。** 这个工具**不命中缓存**，也没有缓存参数；它会**记录**，记下来的是**交给你的那一份**（被截断、被范围限制过的那些字符），用途是回头去看 FTP 取回来的结果。本地文件不记 —— 原件就在盘上，再读一次就有。要用缓存，去 `cache` 工具拿。

#### 不带范围（完整读）

**行为**：把整份内容读出来。

**返回**：内容 + **凭据**（`cookie`）。

#### 带范围（`skipline`/`offset`/`length`/`takeline`/`regex`）

**行为**：先按行取（`skipline`），再按字符取（`offset`/`length`），或按 `regex` 找匹配。

**返回**：内容（**不给凭据**）——只读了一段，不算看过全貌。

#### 超过上限（被截断）

**行为**：只交付 `16000` 字符。

**返回**：内容 + "范围内还有 N 字符未给出" + "全文共 N 字符"（两条一起给）；**不给凭据**。

### 2. 列清单 `list`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 同 `read` | 默认 `null`。同 `read` |
| `path` | `string` | 目标内的路径 | 必填。可以是**目录**、**压缩包**，**也可以是一个文件** |
| `depth` | `int` | 递归深度：`0` = **只当前文件夹** | 默认 `0`；≥ 0 |
| `limit` | `int` | 每层最多展示多少条（文件 + 文件夹） | 默认 `0` = 按层递减（见常量）；上限 `200` |
| `type` | `string?` | 只列 `file` / 只列 `dir` | 默认 `null` = 两者 |
| `meta` | `string?` | 逗号分隔的属性名 | 默认 `null`。只认 `created`（创建时间）、`modified`（修改时间）、`size`（大小）、`count`（目录下有多少条目）；认不出的 → 报错 |
| `regex` | `string?` | 条目过滤 | 默认 `null`。正则语法非法 → 报错 |
| `cookie` | `string?` | 追踪 cookie | 默认 `null`。**只在要看"正在被追踪、还没落盘"的那个压缩包时给** |

常量：

- `limit = 0` 时按层递减：**当前层 `200`、递归 1 层 `100`、2 层 `50`、3 层及以后 `20`**
- **最大 `200`**（`limit` 给更大的值也按 `200` 算）
- 目录树凭据的门槛：**完全穷举**——整棵树都交付出去（没被 `depth`/`limit` 截断，输出也没超 `16000` 字符）。**穷举不完就没有凭据**（凭据的目的是让 AI 知道自己在动什么）

#### 完整枚举

**行为**：把整棵树列出来（没被 `depth`/`limit` 截断，且输出没超 `16000` 字符）。

**返回**：树形清单 + **目录树凭据** + 条目总数 + **总大小**。删目录、合并文件夹要的就是它。

#### 被截断

**行为**：列到截断处为止。

**返回**：清单 + 写明被截断；**不给目录树凭据**。

#### 指向一个文件

**行为**：不列目录，只取该文件的元数据（跟着 `meta` 给）。

**返回**：路径 + `meta` 要的属性（如 `size`、`modified`）。**这里就能拿到它的凭据**——覆盖它、删它、拿它打包都用得上。

## 二、写入

### 3. 写 `write`

只管两件事：**新建**和**覆写**。改动已有内容里的某几处，用 `replace`。

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 同 `read` | 默认 `null`。同 `read` |
| `path` | `string` | 目标内的路径 | 必填。同 `read` |
| `content` | `string` | 整份内容 | 必填 |
| `encoding` | `string?` | 写回编码 | 默认 `null` = 用读它时的编码；新建 = UTF-8 无 BOM。写不出 → 报错 |
| `cookie` | `string?` | 凭据 | 默认 `null`。**覆写已有的对象 → 必填**；对不上 → 不写。新建不要 |

#### 目标不存在（新建）

**行为**：直接建，不要凭据。

**返回**：`# 已写入` + 路径 + **下一个凭据**。

#### 目标已有内容、没给 `cookie`

**行为**：不执行。

**返回**："会发生什么"的**影响清单**，并说明这不算失败。

#### 目标已有内容、给了 `cookie` 且对得上

**行为**：执行。

**返回**：`# 已写入` + 涉及的路径 + **下一个凭据**。

#### `cookie` 对不上

**行为**：不执行。

**返回**：现状 + 新的影响清单——这期间它被改过。

### 4. 替换 `replace`

改动已有内容里的某几处。默认**按字面**找，`regex = true` 时才把 `pattern` 当**正则**，这时 `replacement` 里可以引用捕获到的内容。

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 同 `read` | 默认 `null`。同 `read` |
| `path` | `string` | 目标内的路径 | 必填 |
| `pattern` | `string` | 要匹配的内容；`regex = true` 时是**正则** | 必填。语法非法 → 报错；没命中 → 报错 |
| `replacement` | `string` | 替换成什么；`regex = true` 时可引用捕获组，如 `$1`、`${name}` | 必填 |
| `regex` | `bool` | **是否把 `pattern` 当正则** | 默认 `false` = 按字面匹配 |
| `encoding` | `string?` | 写回编码 | 默认 `null` = 用读它时的编码 |
| `cookie` | `string?` | 凭据 | **必填**；对不上 → 不改 |

#### 命中一处

**行为**：替换掉。

**返回**：`# 已替换` + 路径 + **下一个凭据**。

#### 命中多处

**行为**：不执行。

**返回**：命中 N 处的清单；要你收紧匹配（或打开 `regex` 用更精确的写法）。

#### 没命中

**行为**：不执行（不自动创建）。

**返回**：`Error: ` + 没命中。

#### 没给 `cookie` / `cookie` 对不上

**行为**：不执行。

**返回**：同 `write` —— 影响清单（或现状 + 新清单）。

## 三、删除、移动与复制

### 5. 删 `delete`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 同 `read` | 默认 `null`。同 `read` |
| `path` | `string` | 要删的对象 | 必填。必须存在 |
| `cookie` | `string?` | 凭据 | **必填**。删目录时它是"读整棵树"那份；**删压缩包内的条目时，是那个条目自己的凭据** |

#### 没给 `cookie` / `cookie` 对不上

**行为**：不执行。

**返回**：`Error: ` + **怎么获得 cookie**（去 `read` / `list` 拿）。**不报告内容**——你去取凭据的时候自然会看到。

#### 能进回收站

**行为**：删入回收站。

**返回**：`# 已删除（回收站）` + 去哪能找回。

#### 进不去回收站（过大装不进回收站、网络盘、可移动盘、只读卷）

**行为**：**不执行**。

**返回**：`Error: ` + 为什么进不去 + 让用户手动处理——**不允许 agent 执行这个高危操作**。

#### 远端（FTP）

**行为**：**不执行**。

**返回**：说明远端没有回收站、删了不可恢复，请用户手动处理。

### 6. 移 `move`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 源存储/容器 | 默认 `null`。同 `read` |
| `path` | `string` | 源路径 | 必填。必须存在 |
| `toTarget` | `string?` | 目标存储/容器 | 默认 `null`。同 `read` |
| `toPath` | `string` | 目标路径 | 必填 |
| `cookie` | `string?` | 源那一侧的凭据 | 默认 `null`。**跨 target 或跨卷 → 必填** |
| `toCookie` | `string[]?` | 目标那一侧的凭据 | 默认 `null`。**目标已有内容（合并文件夹、覆盖文件、覆盖压缩包内的条目）→ 必填**。顺序无关——每个 cookie 拿去和目标比对，比对本身就是 hash 比对，对得上就用 |

#### 同一个 `target` 且同一卷

**行为**：直接移，不要凭据（移回来即可，可逆）。

**返回**：`# 已移动` + 源路径 + 目标路径。

#### 跨 `target` 或跨卷

**行为**：先落定目标（拷贝 + 校验），再删源；**中途失败源不删**。

**返回**：`# 已移动`；失败时报告两边各是什么状态。

#### 目标已有内容、没给凭据（冲突 ≤ `15` 个）

**行为**：不执行。先做一遍**目录验证**——查清哪几个目录会合并、哪几个文件会冲突。

**返回**：

- **会合并的目录**：逐个列出 —— 每个都要**它自己的 cookie**；
- **会冲突的文件**：逐个列出 —— 每个都要**它的 cookie**（用来替换）；
- 末尾一句：**请确认意图；如果确认，用别的工具去取 cookie。**

#### 冲突的文件超过 `15` 个

**行为**：照样做目录验证，但**带上提示**。

**返回**：上面那份清单 + 一句：**冲突太多，建议由用户手动移动。**

#### 冲突的文件超过 `50` 个

**行为**：不执行，也不逐个列 cookie。

**返回**：`有 N 个文件路径冲突。如果要覆盖，请让用户来处理 —— 你无法从这个工具得到授权。`

### 7. 复制 `copy`

把**源**复制到**目标**，源留着。**跨存储搬东西就用它**：FTP → 本地是下载，本地 → FTP 是上传。

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 源存储/容器 | 默认 `null`。同 `read` |
| `path` | `string` | 源路径 | 必填。必须存在 |
| `toTarget` | `string?` | 目标存储/容器 | 默认 `null`。同 `read` |
| `toPath` | `string` | 目标路径 | 必填 |
| `toCookie` | `string[]?` | 目标那一侧的凭据 | 默认 `null`。**目标已有内容（合并文件夹、覆盖文件、覆盖压缩包内的条目）→ 必填**。顺序无关——每个 cookie 拿去和目标比对，比对本身就是 hash 比对，对得上就用 |

#### 目标不存在

**行为**：直接复制。

**返回**：`# 已复制` + 源路径 + 目标路径。

#### 目标已有内容、没给凭据（冲突 ≤ `15` 个）

**行为**：不执行。先做一遍**目录验证**——查清哪几个目录会合并、哪几个文件会冲突。

**返回**：

- **会合并的目录**：逐个列出 —— 每个都要**它自己的 cookie**；
- **会冲突的文件**：逐个列出 —— 每个都要**它的 cookie**（用来替换）；
- 末尾一句：**请确认意图；如果确认，用别的工具去取 cookie。**

#### 冲突的文件超过 `15` 个

**行为**：照样做目录验证，但**带上提示**。

**返回**：上面那份清单 + 一句：**冲突太多，建议由用户手动移动。**

#### 冲突的文件超过 `50` 个

**行为**：不执行，也不逐个列 cookie。

**返回**：`有 N 个文件路径冲突。如果要覆盖，请让用户来处理 —— 你无法从这个工具得到授权。`

#### 跨 `target`（下载 / 上传 FTP）

**行为**：源与目标不在同一存储上时，按源读、按目标写；源不动。

**返回**：`# 已复制` + 两边路径；失败时报告两边各是什么状态。

## 四、网络

### 8. 取 / 下载 `fetch`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `url` | `string` | 目标地址 | 必填。必须以 `http://` 或 `https://` 开头 |
| `method` | `string?` | HTTP 方法 | 默认 `null` = `GET`。只认 `GET`/`POST`/`PUT`/`PATCH`/`DELETE`/`HEAD`/`OPTIONS` |
| `head` | `string?` | 请求头 | 默认 `null`。必须是合法的 JSON 对象字符串 |
| `body` | `string?` | 请求体 | 默认 `null` |
| `targetPath` | `string?` | 下载到哪个本地路径 | 默认 `null`。必须是不存在的本地绝对路径；目标已有文件 → 要 `cookie` |
| `cookie` | `string?` | 覆盖本地已有文件的凭据 | 默认 `null`。只在 `targetPath` 已有文件时必填 |

常量：

- 超时 `15` 秒
- 重试上限 `3` 次
- 响应截断 `16000` 字符
- **限流：只作用于下载**（给了 `targetPath` 的那一路），取内容不受它管 —— 目的是别让 AI 一口气掏个巨物下来，把磁盘/带宽吃干。额度 **`10 MB`**，**每分钟恢复 `1 MB`**

**拦截：不做判定。** `2xx` 就是成功，内容照给——判断交给调用方。

#### 不给 `targetPath`（取内容）

**行为**：把响应取回来，**全额进缓存**，哪怕交给你的那一份被截断——因为 **http 没有偏移**，一次只给得了这么多（`length` 默认 `5000`），超了就再也要不到后半段，只有缓存里留着完整的。

**返回**：内容（≤ `16000` 字符）；要读后半段，去 `cache` 工具拿。

#### 给了 `targetPath`（下载）

**行为**：下载到该路径；**不进内容缓存**，只留一条元数据记录。

**返回**：落盘路径 + 一条元数据记录——原件已经在磁盘上了，去读原件。

### 9. 缓存 `cache`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `key` | `string?` | 要读/落盘的缓存条目 | 默认 `null` = **列出缓存**；给了必须是存在的条目 |
| `path` | `string?` | 落盘到哪 | 默认 `null`。给了（且给了 `key`）→ 落盘；本地绝对路径，**目标必须不存在** |
| `page` | `int` | 列缓存时翻到第几页 | 默认 `0`。**只在 `key` 为 `null`（列缓存）时有意义** |

**进缓存的不等于会命中。** 进缓存的是**取回来的东西**：**http 的全文**（没有偏移，交付被截断时后半段只能靠它）与 **FTP 的读取**。本地文件不进（原件在盘上）。**命中一律不发生**——要用就来这里拿。

常量：

- 缓存 TTL `7` 天 —— 到点就删，启动时异步扫
- 容量上限 `64 MB` —— 超出按 LRU 淘汰
- 落点 `%LOCALAPPDATA%\ZMS.MCP\cache`（拟），环境变量 `ZMS_MCP_CACHE` 可覆盖
- 账：`64 MB` ÷ 单条（≤ `16000` 字符）≈ `4000` 条；`7` 天要撑满得平均每 `2.5` 分钟读一次 —— **先到期、后撑满**，容量是兜底
- 列缓存**分页**：一次一页（`page`）**每页 `50` 条**，所以不再受"一次 `16000` 字符"的死限

#### `key` 为 `null`

**行为**：列出缓存条目（一页）。

**返回**：这一页的条目，每行一条：

```
tool | args | time | key | 结果
```

条目多时**翻页**：`page`。

**结果**那一列写这次调用落下了什么，例如 `正常`、`截断 N 字符`、`范围内还有 N 字符被截断`。

#### 给了 `key`

**行为**：取出该条目的内容，**一次最多 `5000` 字符**。

**返回**：内容（可能被截断）——它给你看个大概。**要看全文，用 `key` + `path` 落盘，再用 `read` 的范围参数读。**

#### 给了 `key` + `path`

**行为**：把缓存落盘到 `path`。

**返回**：落盘路径——之后就能用 `read` 的范围参数去看它的其他部分。

## 五、FTP 会话

### 10. 登录 `login`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `host` | `string` | 主机 | 必填 |
| `port` | `int` | 端口 | 默认 `21`；1–65535 |
| `user` | `string?` | 用户名 | 默认 `null` = 匿名 |
| `password` | `string?` | 密码 | 默认 `null` = 匿名；**只存内存、不落盘、日志与列表里打码** |

常量：

- 默认端口 `21`
- 会话数上限 `16`（拟）
- 空闲超时 `10` 分钟（拟）

**行为**：建立会话，之后所有操作把句柄填进 `target`。

**返回**：`ftp:<session>` 句柄。

### 11. 注销 `logout`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `session` | `string?` | 要关的会话 | 默认 `null` = 关掉全部；给了必须是已知会话 |

#### 给了 `session`

**行为**：只关那一个。

**返回**：关掉的句柄。

#### 没给 `session`

**行为**：关掉全部。

**返回**：关了几个。**不知道句柄时，这是唯一允许的调用。**

## 六、浏览器

### 12. 浏览器 `browse`

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `url` | `string` | 要打开的地址 | 必填。必须以 `http://` 或 `https://` 开头 |
| `action` | `string?` | `open` = 打开就返回；`wait` = 等页面稳定再返回 | 默认 `null` = `open`；只认这两个 |
| `waitFor` | `string?` | 等待条件，如 `networkidle` / `5s` | 默认 `null`。只在 `action=wait` 时有意义 |
| `timeout` | `int` | 最多等多久 | 默认 `60` 秒；> 0 |

常量：

- 默认超时 `60` 秒 —— **浏览器启动要时间**，给少了不够
- **浏览器依赖**：用 **Playwright** 驱动**系统上本来就有的 Chrome 内核浏览器**，**不额外下载浏览器**。假定"人人都有"：**Edge `120`（拟）以上，或 Chrome `120`（拟）以上**，机器上有哪个就用哪个
- **不支持套壳**：360 / QQ / 夸克这类（内核被改过，驱动不上）。**驱动不起来就如实报错**，让用户装一个标准 Edge / Chrome —— 不猜、不降级

#### JS 渲染

**行为**：打开页面、等 JS 跑完。**结果不进缓存**。

**返回**：页面内容。

#### 人机验证

**行为**：服务自己起**可见**的浏览器打开页面，**同步等人过验证**，最长 **`60` 秒**（到点就放弃这一次）。验证产物（会话）留在服务进程手里。

**返回**：过了就返回页面内容；没等到就如实说"`60` 秒内没有通过验证"。

## 七、压缩包（走拟定）

压缩包**不造新工具**：读写它用的还是上面那批工具（`read` / `list` / `copy` / `move` / `delete`），只是**当它正在被追踪时，写操作变成"攒一条拟定"**。

### 13. 追踪压缩包 `track_archive`（名字拟）

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `target` | `string?` | 压缩包在哪个存储上 | 默认 `null` = 本地。**FTP 上的压缩包追踪不了** |
| `path` | `string` | 要追踪的压缩包 | 必填。**可以还不存在**（那就是"要创建"） |
| `format` | `string?` | 创建时的格式 | 默认 `null`。包**已存在时忽略**；不存在时必填，只认 `zip` / `7z` / `tgz` / `ztsd` |
| `cookie` | `string?` | 传回追踪 cookie = **解除追踪** | 默认 `null` |

#### 不带 `cookie`（开始追踪）

**行为**：把这个压缩包标成**拟定态**。

**返回**：追踪 cookie + 现在攒了哪几条。

#### 带 `cookie`（解除追踪）

**行为**：清掉追踪与全部拟定。

**返回**：删掉了几条。

#### 包在拟定态时，`copy` / `move` / `delete` 打到它上面

**行为**：**不落盘**，各记一条拟定，不改任何字节。**要凭据**——被涉及的那个条目自己的（删它 / 覆盖它），跟覆盖一个文件是同一条规矩。

**返回**：`# 拟定已更新` + 这一条改了什么 + 现在共几条。

#### 包不在拟定态

**行为**：`read` / `list` / `copy` / `move` / `delete` 照原本那样直接落盘。

**返回**：各自的正常返回。

#### `read` / `list` 打进包里

**行为**：**永远直读磁盘上现在那个包**，跟有没有在追踪无关——**查看不需要追踪**。

**返回**：包内现在的内容。

### 14. 落盘预检 / 落盘 `confirm`（名字拟）

参数：

| 参数名 | 参数类型 | 参数作用 | 参数校验 |
|---|---|---|---|
| `cookie` | `string` | 追踪 cookie | 必填 |
| `applyCookie` | `string?` | 空 = **落盘预检**；给了 = **落盘** | 默认 `null` |

#### 落盘预检（不给 `applyCookie`）

**行为**：不碰磁盘。算一遍合计大小与分档。

**返回**：

- 攒了哪几条（增加 / 删除 / 修改 各几条）；
- 合计大小；
- **落盘后包里会变成什么样**（包内清单）；
- 分档结果；
- 落盘 cookie。

#### 落盘（给了 `applyCookie`）

**行为**：重读磁盘比对（拟定期间包被人动过就**拒绝落盘**）→ 在内存里把攒的那几条**重放** → 攒出新包 → 原子替换。

**返回**：`# 已落盘` + 包路径 + 包大小。

常量：

- 合计 **> `1 GB`** → **不给打**
- 合计 **> `50 MB`** → **先向宿主确认**——MCP 支持向用户提问就走那条路；**不支持就直接打**，不拦
- 支持的格式：`zip` / `7z` / `tgz` / `ztsd`
- **`pack` 工具作废**（创建压缩包 = 追踪一个还不存在的包 + 往里 `copy` + 落盘）
- **`containerCookie` 作废**——包内改动要的是**被涉及条目自己**的凭据（跟覆盖一个文件同一条规矩），走 `cookie` / `toCookie`

## 没做的（列出边界）

免得将来有人以为"没写就是没想"。这一节只列**明确不做、或先不做**的事。

| 事 | 现状 |
|---|---|
| 拦截判定 | **有意不做**：`2xx` 即是成功，判断交给调用方 |
| 单文件元数据 | 没有独立工具，走 `list` 指到那个文件 + `meta` |
| 两个目录差在哪 | 没有（痛点 A6 里的一半） |
| 限流 | 只做在 `fetch` 的**下载**那一路；取内容不管 |
