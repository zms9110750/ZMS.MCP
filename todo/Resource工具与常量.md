## 约定

- 参数类型用 C# 可空语法：`:string` = 必填；`string?` = 可空（"没给"与"给了空串"等价）。参数的默认值写在各自工具的参数表里。
- 返回恒为 **markdown 文本**（`string`）；失败时第一段以 `Error: ` 开头，协议层 `isError = true`。
- **缺凭据 / 凭据对不上都不算失败**（`isError = false`）——它们是两段式的正常路径。
- 三个短标识**绝不混用**：`cookie` = 凭据、`key` = 缓存标识、`session` = 会话（会话只是 `target` 的一种取值）。
- 寻址：`target` 空 = 本地（`path` 是全称，可带盘符）；`ftp:` 前缀 = FTP 会话（`path` 是远端纯路径）；其余非空 = 压缩包路径（`path` 是包内纯路径）。认不出来**报错**，不降级到本地。
- **凭据从"读完整份"来**：读完整份 → `cookie`；只读一段（带 `offset`/`length`/`skipline`/`takeline`/`regex`）→ 只有 `key`；读不完整份 → 两样都没有。
- **多大算"读完整份"**：`256 KB` **[拟]**。这是凭据规则的临界值——大了门槛虚设，小了普通文件都动不了。
- **目录树要算"完整枚举"**：没被 `depth`/`limit` 截断，且总条目数不超过 `1000` **[拟]**。只有完整枚举才给"目录树凭据"。
- 读的编码判定：BOM（UTF-8 / UTF-16 LE / BE）→ 严格试 UTF-8 → **拒绝**；不给 `encoding` 时按此。
- 二进制判定：头 `8 KB` 内含 `0x00` 即当二进制 **[拟]**。
- 单次返回上限 `5000` 字符，超出截断并注明"（已省略 N 字符）"。
- 正则命中分级：`>20` 只给行号；`>5` 给上下 1 行；`≤5` 给上下 3 行。
- 缓存三类条目：**读结果**（可命中）、**写结果**（列得出、**永不命中**）、**下载记录**（只有元数据，没有内容也不给读内容的标识）。**命中缓存的那次读不给凭据。**
- 工具名 snake_case、参数名 camelCase；实现时每个工具带 `[McpServerTool(ReadOnly, Destructive, Idempotent, OpenWorld)]` 与**纯英文** `[Description]`（完整契约）。

## 工具

十个。`[R/D/I/O]` = 实现时要填的四个布尔（ReadOnly / Destructive / Idempotent / OpenWorld）。

### 一、读取

#### 1. 读内容 `read`　`[true/false/true/false]`

读本地文件、远端文件或包内条目。**读完整份给凭据**；只读一段只有缓存标识；读不完整份两样都没有。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `target` | `string?` | 空 = 本地；`ftp:<session>` = 会话；其余 = 压缩包路径 |
| `path` | `:string` | 目标内的路径；`target` 为空时是全称（可带盘符） |
| `offset` | `integer` | 跳过多少字符；默认 `0` |
| `length` | `integer` | 至多展示多少字符；默认 `0` = 不限 |
| `skipline` | `integer` | 跳过多少行；默认 `0` |
| `takeline` | `integer` | 至多取多少行；默认 `0` = 不限 |
| `encoding` | `string?` | 编码名（`gbk` / `utf-8`）；空 = 按判定的顺序 |
| `regex` | `string?` | 正则；命中按数量分级给上下文 |
| `cache` | `boolean` | 默认 `true`；`false` = 真去拿并覆盖缓存 |

拟定返回：

- 局部读 → 内容 + `- 缓存标识：<key>`
- 完整读 → 内容 + `- 凭据：<cookie>` + `- 缓存标识：<key>`
- 读不完 → 内容（截断）+ `未交付全文 → 没有凭据，不能改，也不能删`
- 命中缓存 → 只给 `key` 与 `这是缓存，取自 <时间>`，**不给凭据**

#### 2. 列清单 `list`　`[true/false/true/false]`

列目录、远端目录或包内清单。**完整枚举**才给"目录树凭据"——删目录、移动合并要用它。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `target` | `string?` | 同上 |
| `path` | `:string` | 同上 |
| `depth` | `integer` | 递归深度，`1` = 只当前层；默认 `3` |
| `limit` | `integer` | 每层最多展示的条目数（文件 + 文件夹）；默认 `20` |
| `type` | `string?` | `file` / `dir`；空 = 两者 |
| `meta` | `string?` | 逗号分隔属性名，如 `created,modified,size` |
| `regex` | `string?` | 条目过滤 |

拟定返回：树形清单；完整枚举时追加 `- 目录树凭据：<cookie>` 与条目总数。

### 二、写入

#### 3. 写 `write`　`[false/true/false/false]`

新建 / 覆写 / 替换部分 / 批量替换 / 追加。**改到已有内容就要凭据**；没有凭据只把"会发生什么"摊出来，不执行，且不算失败。新建不要凭据。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `target` | `string?` | 同上 |
| `path` | `:string` | 同上 |
| `content` | `string?` | 整份新内容：目标不存在 = 新建；已存在 = 覆写（要凭据） |
| `oldString` | `string?` | 替换源，必须在文件里唯一 |
| `newString` | `string?` | 替换为；空串 = 删除这一段 |
| `edits` | `string[]?` | 批量替换，按序应用 |
| `append` | `string?` | 追加的文本行，**要凭据** |
| `encoding` | `string?` | 写回编码；空 = 用读它时的编码（新建 = UTF-8 无 BOM） |
| `cookie` | `string?` | 凭据；改到已有内容时必填 |
| `containerCookie` | `string?` | 包内操作时必填（包自己的目录树凭据） |

拟定返回：

- 目标已有内容、无凭据 → `# 会发生什么（未执行）` + 影响清单
- 有凭据且对得上 → `# 已写入` + 涉及文件 + **下一个凭据**
- 凭据对不上 → 现状 + 新的影响清单

### 三、删除与移动

#### 4. 删 `delete`　`[false/true/false/false]`

删文件 / 目录（连同里面）/ 包内条目。**走回收站**；进不去回收站（超配额、网络盘、可移动盘、只读卷）就**先明说"这次是真删、捡不回来"**，再动手。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `target` | `string?` | 同上 |
| `path` | `:string` | 要删的对象 |
| `cookie` | `string?` | 凭据；**删目录就是"读整棵树"那份凭据** |
| `containerCookie` | `string?` | 包内操作时必填 |

拟定返回：`# 已删除（回收站）` + 去哪能找回；或 `# 已删除（不可恢复：<原因>）`。远端（FTP）一律不可恢复，必须写明。

#### 5. 移 `move`　`[false/true/false/false]`

移动 / 改名。**同一个 `target` 且同一卷 → 不要凭据**（移回来即可）；**跨 `target` 或跨卷 → 要源的凭据**（那等于"删源 + 在目标处造一个"，实际是拷贝 + 删）；目标已有内容 → 还要**目标的**凭据。失败时**源不删**，把两边状态报出来。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `target` | `string?` | 源 target |
| `path` | `:string` | 源路径 |
| `toTarget` | `string?` | 目标 target |
| `toPath` | `:string` | 目标路径 |
| `cookie` | `string?` | 源的凭据（跨 target / 跨卷时必填） |
| `toCookie` | `string?` | 目标的凭据（目标已有内容时必填） |
| `containerCookie` | `string?` | 任一侧在包里时必填 |

### 四、网络

#### 6. 取 / 下载 `fetch`　`[false/false/false/true]`

取 URL 内容（进缓存），或下载到本地路径。**下载不进内容缓存**，只留一条元数据记录——原件已经在磁盘上了，去读原件。**不做拦截判定**：`2xx` 就是成功，内容照给；怀疑是挑战页就自己 `cache=false` 重取，或调 `browse`。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `url` | `:string` | `http://` 或 `https://` |
| `method` | `string?` | `GET` / `POST` / `PUT` / `PATCH` / `DELETE` / `HEAD` / `OPTIONS`；默认 `GET` |
| `head` | `string?` | 请求头，JSON 对象字符串 |
| `body` | `string?` | 请求体文本 |
| `targetPath` | `string?` | 本地绝对路径；下载用 |
| `cookie` | `string?` | 覆盖本地已有文件时的凭据 |
| `cache` | `boolean` | 默认 `true` |

### 五、缓存

#### 7. 缓存 `cache`　`[false/false/true/false]`

`op` = `list` / `read` / `save`。列表**不展示正文**，但每条要能回答四件事：**是什么、什么时候、用什么参数、有没有内容可读**。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `op` | `:string` | `list` / `read` / `save` |
| `key` | `string?` | 要读或落盘的条目 |
| `path` | `string?` | 落盘到哪（`op=save`）；目标必须不存在 |

### 六、FTP 会话

#### 8. 登录 `login`　`[false/false/false/true]`

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `host` | `:string` | 主机 |
| `port` | `integer` | 默认 `21` |
| `user` | `string?` | 空 = 匿名 |
| `password` | `string?` | 空 = 匿名；**只存内存、不落盘、列表里打码** |

拟定返回：`ftp:<session>` 句柄。

#### 9. 注销 `logout`　`[false/false/true/true]`

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `session` | `string?` | 空 = 关掉全部，并报告关了几个。**不知道句柄时，这是唯一允许的调用** |

### 七、浏览器

#### 10. 浏览器 `browse`　`[false/false/false/true]`

跑 JS 渲染，或把验证交给用户过（服务自己起可见浏览器）。**结果不进缓存**——调 API 拿的是数据，等 JS 跑出的是页面。

参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `url` | `:string` | 要打开的地址 |
| `action` | `string?` | `open`（默认）/ `wait` |
| `waitFor` | `string?` | 等待条件，如 `networkidle` / `5s` |
| `timeout` | `integer` | 默认 `30` 秒 |
